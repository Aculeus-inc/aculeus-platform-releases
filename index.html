The first time you open it

Windows: open the file you downloaded. If Windows shows a blue warning, choose More info, then Run anyway.

Mac: open the zip, move Aculeus to Applications and open it. If the Mac stops it, go to System Settings, Privacy & Security, and choose Open Anyway.

Not sure which Mac you have? Apple menu, About This Mac. "Chip: Apple" means Apple silicon; "Processor: Intel" means Intel.
