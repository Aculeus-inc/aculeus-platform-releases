# Aculeus downloads

Aculeus is one place where a client's staff, builders and agents work together. Download it from **https://aculeus-inc.github.io/aculeus-platform-releases/**, which offers the file for your computer. Or pick it here:

- **Windows**: [Aculeus-windows-x64.exe](https://github.com/Aculeus-inc/aculeus-platform-releases/releases/latest/download/Aculeus-windows-x64.exe)
- **Mac with Apple silicon** (M1 and later): [Aculeus-mac-apple-silicon.zip](https://github.com/Aculeus-inc/aculeus-platform-releases/releases/latest/download/Aculeus-mac-apple-silicon.zip)
- **Mac with an Intel chip**: [Aculeus-mac-intel.zip](https://github.com/Aculeus-inc/aculeus-platform-releases/releases/latest/download/Aculeus-mac-intel.zip)

These files are not signed yet, so approve the app once. On Windows: More info, then Run anyway. On a Mac: open the zip, move Aculeus to Applications, open it, then System Settings, Privacy & Security, Open Anyway.

Install it once: Aculeus then keeps itself up to date. It looks for a newer release when it opens and every hour, downloads it and asks to restart. You stay signed in.

The older Aculeus desktop app for builders is at [aculeus-desktop-releases](https://github.com/Aculeus-inc/aculeus-desktop-releases).
